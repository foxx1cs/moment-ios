# Moment · iOS

Нативное приложение обратного отсчёта на SwiftUI, вдохновлённое предоставленным примером Reach. Собственное название, оформление и иконка. iPhone и iPad, iOS 17+, Xcode 16+; без внешних библиотек, регистрации, рекламы и покупок.

## Что реализовано

- Создание, редактирование и удаление событий: название, дата, часы, минуты и **секунды**, заметка, 12 символов и 5 цветов.
- Обратный отсчёт **дни : часы : минуты : секунды** в приложении. При возвращении из фона время пересчитывается по дате события, поэтому счётчик не накапливает погрешность.
- Главное событие, индикатор пройденного времени, списки будущих и завершённых событий.
- Виджеты WidgetKit: маленький и средний на главном экране, прямоугольный под часами на экране блокировки.
- Независимый выбор события для каждого виджета через App Intents. Без выбора показывается главное событие приложения.
- Нажатие на виджет открывает событие. Удалённое выбранное событие не подменяется другим: виджет предложит изменить настройку.
- Основное хранилище в Application Support самого приложения с атомарной записью. Создание, редактирование и сохранение событий работают без App Groups, в том числе после переподписи через Sideloadly.
- При доступной App Group приложение передаёт копию событий виджету. Ошибка синхронизации не отменяет локальное сохранение и не блокирует кнопки. При первом запуске новой версии существующий доступный архив App Group переносится в локальное хранилище; повреждённый архив не перезаписывается молча.
- Русский интерфейс, поддержка системных размеров текста и подписи VoiceOver для основных элементов.

## Открыть и запустить

1. Откройте **`Moment.xcodeproj`** на Mac с Xcode 16 или новее. Генерировать проект или устанавливать зависимости не нужно.
2. Выберите схему **Moment** и симулятор iPhone с iOS 17+; нажмите **⌘R**. Для запуска на симуляторе обычно не требуется команда разработчика.
3. Создайте событие кнопкой «+». Время задаётся до секунды: поле «Секунды» находится под выбором даты.
4. Для физических устройств настройте подпись. App Groups нужны для виджетов; само приложение работает и без них.

### Подпись для собственного iPhone

В `Config/Shared.xcconfig` задайте уникальный `MOMENT_BUNDLE_PREFIX`, например `ru.yourname.moment`, и `DEVELOPMENT_TEAM` своей команды Apple Developer. Не меняйте `MOMENT_APP_GROUP` отдельно: он вычисляется как `group.<prefix>`.

В Xcode → Signing & Capabilities для **Moment** и **MomentWidgets** проверьте:

- выбрана одна и та же команда и включён Automatically manage signing;
- есть capability **App Groups**, в обоих таргетах включена одна и та же группа `group.<ваш prefix>`;
- группа зарегистрирована для обоих App ID в Apple Developer.

App Groups на физическом устройстве требуют provisioning profile с этим entitlement; бесплатная Personal Team может не поддерживать эту возможность. Начиная с 1.0.1 отсутствие группы не мешает пользоваться приложением: события сохраняются локально, а в разделе виджетов отображается сообщение об их недоступности. Блокирующего предупреждения при обычном запуске без App Group нет.

Идентификаторы приложения, расширения и App Group берутся из одного `.xcconfig`. Значение группы в Info.plist и entitlements подставляется при сборке. Основная локальная копия не зависит от доступности группы. Миграция из другой, уже недоступной App Group невозможна; если события были только в старой группе, сначала установите обновление с доступом к ней.

### Добавить виджет

Сначала один раз запустите приложение и создайте событие. Затем зажмите экран блокировки → «Настроить» → экран блокировки → виджеты под часами → **Moment**. Нажмите на добавленный виджет в режиме настройки и выберите событие. Тот же выбор доступен через «Изменить виджет» на главном экране. Инструкция также встроена в приложение.

## IPA для Sideloadly

На Mac с Xcode можно собрать неподписанный IPA командой:

```bash
bash Scripts/build_ipa.sh
```

Результат — `build/Moment-unsigned.ipa`: архив для устройства arm64 с вложенным расширением виджета. Это неподписанная сборка, которую нужно подписать при установке. Сценарий проверяет наличие исполняемых файлов приложения и расширения, архитектуру, Info.plist и целостность ZIP. На Linux он завершится с сообщением об отсутствии macOS/Xcode.

Для облачной сборки есть `.github/workflows/build-ipa.yml`. Загрузите проект в корень своего GitHub-репозитория и запустите **Actions → Build unsigned iOS IPA → Run workflow**. Также сборка запускается при push в ветку `moment-ipa`. В завершённом запуске скачайте артефакт `Moment-unsigned-IPA`, распакуйте ZIP и откройте содержащийся в нём `.ipa` в Sideloadly. GitHub может учитывать минуты macOS-сборки в квоте аккаунта.

**Для приложения App Groups не обязательны. Для виджетов требуется App Group, доступная обоим таргетам.** Sideloadly должен корректно переподписать приложение и расширение для доступа к общей группе. Если подпись не поддерживает App Groups, приложение продолжает создавать, редактировать и сохранять события, но передача данных виджету недоступна. Пароль Apple ID и сертификаты в GitHub для неподписанной сборки не нужны. При обновлении используйте тот же Apple ID и идентификатор приложения; удалять предыдущую установку не нужно.

## Секунды и ограничения iOS

В приложении `TimelineView` обновляет интерфейс примерно раз в секунду, а значение каждый раз вычисляется из абсолютной даты, без уменьшения сохранённого счётчика. Прошедшие события останавливаются на нуле. Дата сохраняется как `Date`, поэтому смена часового пояса не меняет оставшееся время; отображение даты использует текущий часовой пояс.

В виджете работает системный **`Text(timerInterval:countsDown:showsHours:)`**. Для него не создаются ежесекундные timeline entries и не запускается фоновый сервис. Формат виджета — общее число **часов : минуты : секунды**; 9 дней — 216 часов. Отдельный непрерывно обновляющийся формат `DD:HH:MM:SS` для виджета не обещается: произвольный SwiftUI-код WidgetKit не исполняет каждую секунду. Дни выделены отдельно в приложении.

Системный таймер отсчитывает секунды при обычном отображении, но iOS управляет отрисовкой: на Always-On, в энергосбережении и в некоторых режимах экрана секунды могут скрываться или обновляться реже. Приложение не может гарантировать ежесекундную перерисовку на постоянно заблокированном экране. Таймер ограничен датой окончания и не должен уходить в отрицательное время; отдельная timeline entry переключает состояние на `00:00:00`. WidgetKit может задерживать обновление данных после редактирования и удаления события.

Это **обычные виджеты**, без Live Activities / Dynamic Island. Приложение не планирует уведомления и не выдаёт сигнал по завершении. После удаления приложения локальные данные могут быть потеряны; облачной синхронизации и резервного экспорта нет.

## Проверки

В папке `MomentTests` — 16 XCTest-проверок расчёта времени, хранения, миграции, отсутствия App Group, ошибок записи и сохранности данных. В `MomentUITests` — проверка полного сценария без App Group: кнопка «Создать событие», ввод названия, сохранение, перезапуск и проверка события, затем открытие редактора кнопкой «+». Она работает с отдельным тестовым файлом и не меняет пользовательские события. Запуск на Mac: **⌘U**, `bash Scripts/test_ios.sh` или:

```bash
xcodebuild -project Moment.xcodeproj -scheme Moment \
  -destination 'platform=iOS Simulator,name=iPhone 16' test
```

Имя симулятора замените на установленное (`xcrun simctl list devices available`).

Структурная проверка без Xcode:

```bash
python3 Scripts/validate_project.py
```

Она проверяет ссылки проекта, членство исходников в таргетах, встраивание расширения, конфигурацию App Groups, ресурсы и схему. Дополнительная синтаксическая проверка Swift и независимый разбор `.pbxproj` доступны после установки `Scripts/validation-requirements.txt` в отдельное Python-окружение; это зависимости только проверки, не приложения.

UI-тест создал событие при принудительно недоступной App Group, перезапустил приложение, подтвердил сохранение и проверил открытие редактора кнопкой «+». ## Структура

```text
Moment/             SwiftUI: экраны, состояние, иконка
Shared/             Модель, расчёт времени, локальное и общее хранилище, цвета
MomentWidgets/      WidgetKit, App Intent, выбор событий
MomentTests/        XCTest
MomentUITests/      Создание события и перезапуск без App Groups
Config/             Подпись, Info.plist, entitlements
Moment.xcodeproj/   Готовый проект и общая схема
Scripts/            Проверка и воспроизводимая генерация проекта
```

Если добавляете исходники, включите их в нужные таргеты в Xcode или выполните `python3 Scripts/generate_project.py`. Генератор пересоздаёт `.pbxproj`, схему, Info.plist и entitlements; он не меняет `Shared.xcconfig`. Если меняли генерируемые файлы вручную, сначала перенесите изменения в генератор.
