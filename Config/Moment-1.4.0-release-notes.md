## Moment 1.4.0

Add a photo to an event and its share card, import upcoming events from the iPhone calendar, filter by category and sort by date or name. The notification status screen shows permission and scheduled reminders.

Install the unsigned `Moment-1.4.0.ipa` through Sideloadly, keeping the widget extension enabled. Minimum supported version: iOS 17. Calendar access is requested when opening the importer. Photos are selected through the system picker.

The device archive was built with Xcode 16.4. Focused model tests for the changes ran in the preceding build; see Actions for their results. Installation and the new screens have not been checked on a physical iPhone.
