## Moment 1.0.2

Нативное iOS-приложение с обратным отсчётом до секунды и виджетом WidgetKit.

### Установка

Установите `Moment-1.0.2.ipa` через Sideloadly поверх текущего приложения. После обновления удалите старый виджет, добавьте Moment заново, откройте «Изменить виджет» и выберите «Настройка → Вручную». Укажите название, дату, время и секунды. Расширение MomentWidgets должно остаться включённым при установке.

Ручной виджет работает без App Groups. Выбор сохранённых событий из приложения требует подписи с App Groups.

### Проверка

Архив приложения и расширения для arm64 собран с Xcode 16.4; минимальная версия — iOS 17.0. 22 теста логики и UI создания события прошли в одном запуске GitHub Actions. Отдельный UI-тест на симуляторе добавил виджет, открыл меню режима, выбрал ручную настройку и проверил наличие полей даты и времени. Полный ввод даты и установка на физическое устройство в этих проверках не выполнялись.
